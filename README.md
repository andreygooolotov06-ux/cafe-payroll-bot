# Telegram-бот для підрахунку зарплати персоналу кафе ☕

Бот повністю українською мовою на базі **Python + aiogram 3 + SQLite + openpyxl**.

## Можливості

### Для персоналу (Сушист, Водій, Прибиральниця та інші посади)
- **Автоматичний вхід по персональному посиланню** (`t.me/bot?start=...`) — бот запам'ятовує `Telegram ID` і після будь-якого перезапуску одразу впізнає працівника. Спроба зайти під чужий профіль чи без доступу блокується повідомленням `Недостатньо прав 🔒`.
- **🕒 Внести / змінити зміну**:
  - Дата у форматі `ДД.ММ.РРРР` (бот сам визначає день тижня, наприклад `12.11.2026 (Чт)`).
  - Час у форматі `ГГ:ХХ-ГГ:ХХ` (включно з нічними змінами через північ, наприклад `18:00-02:00`).
  - **Банкети**: позначка банкету та кількості гостей (`кількість × ставка за людину`). Якщо Аня ще не вписала тариф у картці — працівник бачить `Звернись до Ані 🙏`, а Ані одразу приходить сповіщення з кнопкою вказати тариф. Якщо працівник пропустив гостей — показує `Внесіть кількість людей 👥`.
  - **Захист від дублів**: після внесення зміни за дату повторно створити її неможливо — доступна лише кнопка `✏️ Змінити години`.
- **💰 Моя зарплата**: детальна особиста сводка за будь-який період + поточний залишок до видачі.
- **📅 Мої зміни**: список усіх змін по датах і годинах.

### Для власниці (Ані)
- **👥 Працівники**:
  - Додавання нових працівників (будь-які посади, ставка/год, `%` від каси дня, банкетний тариф за людину) та генерація інвайт-посилань.
  - Картка кожного працівника: зміна годин за конкретну дату, зміна ставки, `%`, банкетного тарифу, посади, премії, штрафи, детальний індивідуальний звіт, `🗑 Видалити працівника`.
- **💵 Каса дня**: внесення загальної виручки кафе за будь-яку дату — бот автоматично розраховує `%` для всіх, хто працював у цей день.
- **📊 Загальна звітність**: єдина таблиця по всіх працівниках за обраний період (Сьогодні / Вчора / Тиждень / 2 тижні / Місяць / Минулий місяць / Свій період) + вивантаження в **Excel (`.xlsx`)**.
- **💸 Виплати і баланси**: гнучка система гаманця — можна оплатити конкретні 1–2 дні, видати аванс або закрити весь залишок.

## Швидкий запуск

1. Створіть бота в Telegram через [@BotFather](https://t.me/BotFather) (`/newbot`) і скопіюйте токен.
2. Дізнайтеся свій Telegram ID (наприклад, через [@userinfobot](https://t.me/userinfobot)).
3. Скопіюйте `.env.example` у `.env` та заповніть:
   ```env
   BOT_TOKEN=123456:ABC...
   OWNER_IDS=ВАШ_TELEGRAM_ID
   TIMEZONE=Europe/Kyiv
   DB_PATH=data/cafe_payroll.db
   ```
4. Віртуальне середовище `.venv` вже створене і містить усі залежності. Якщо переноситимете бота на інший ПК з Python 3.14 і нижче:
   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
   А запустити бота можна прямо командою (або подвійним кліком по `start_bot.bat`):
   ```powershell
   .\.venv\Scripts\python.exe run.py
   ```
5. Для запуску автотестів:
   ```powershell
   .\.venv\Scripts\python.exe -m pytest -v
   ```
